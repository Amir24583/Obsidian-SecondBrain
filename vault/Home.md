# Home

Your second brain. Drop things in, and the AI files them into the wiki.

## Find things
- [[wiki/index|Wiki index]]: every page, sorted by topic
- [[wiki/overview|Overview]]: the big picture
- [[wiki/log|Log]]: what was added and when

## Add things
- Save web pages, PDFs and notes into `raw/inbox/` (the Obsidian Web Clipper can save straight there).
- Sync OneNote with the converter: pages land in `OneNote Journals/` and are filed automatically.
- Agents write what they learn to `raw/agents/` (see `AGENTS.md`).

Then run `/ingest` in Claude Code in this folder, or let the automatic run do it.
